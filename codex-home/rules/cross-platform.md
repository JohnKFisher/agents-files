# Cross-Platform

Read when behavior, storage/paths, UX, rendering, build/release, permissions, packaging, or distribution spans more than one platform.

Record the primary platform in the project profile/decision log when it materially guides choices. Prefer the project's primary platform when conventions conflict while avoiding unnecessary breakage elsewhere; native differences are acceptable. Do not broaden compatibility claims, lower deployment targets, or imply tested platform support without approval and verification.

Use platform-neutral path APIs and intentionally handle separators, reserved names, case sensitivity, path length, sandbox/user-writable locations, and platform-specific conventions. Verify the highest-risk affected platform path and state material platforms not checked.
