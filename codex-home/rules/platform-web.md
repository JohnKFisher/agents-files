# Web / Static Site

Read for ordinary browser/frontend/static-site work, Sidelark Labs site content, HTML/CSS/JavaScript, or web build/deploy behavior. Use Tauri rules instead for desktop WebViews.

Prefer simple, fast, accessible, responsive frontend/static approaches with semantic HTML, system-friendly styling, clear navigation, minimal JavaScript, and minimal justified dependencies. Do not introduce frameworks/build systems/deployment platforms without a material need and approval.

For public Sidelark Labs content, avoid hype/fake corporate polish and keep pages concise and useful. Do not change DNS, Cloudflare/deployment settings, redirects, build-output directories, or environment variables without explicit approval.
