# agents-files

Opinionated `AGENTS.md` and agent-rule files for my personal local-first software projects.

These are the real agent files I use across my own projects. They are published as a shareable source repo so other people can copy any files or rules relevant to their personal projects.

This is not a universal standard, not a generic framework, and not a promise that every rule belongs in every project. Treat this repo as copy-and-adapt source material, not something you would want to fork wholesale.

## What you must personalize

If you adapt these files for your own work, review and change the Me-specific defaults before shipping anything:

- About-screen credit rules currently point at Sidelark Labs and John Kenneth Fisher
- some Apple bundle ID guidance defaults to `com.sidelarklabs.<appname>`
- some rule files may not fit your stack, platform, or workflow and should be omitted.
- `docs\agent-projects\` are explicitly my personal projects and likely need to be omitted from your projects (though feel free to adapt any of their rules to your purposes)

## What's here

- `AGENTS.md`: the main root instruction file
- `CLAUDE.md`: a small pointer for Claude Code sessions
- `docs/agent-projects/`: conditional rule files for specific projects I am working on
- `docs/agent-rules/`: conditional rule files for specific kinds of work
- `docs/DECISIONS.md`: a minimal starter decision log template
- `docs/WHERE_WE_STAND.md`: a minimal starter status template

## Notes

These files were developed through real project use, refined over time, and improved with AI assistance alongside my own judgment.
